# 繁體中文溝通與文件規範技能

## 概述
本技能確保 Agent 在與使用者互動、撰寫計畫、記錄進度以及產出任何文件時，皆保持一致的繁體中文語系，以符合使用者的偏好。

## 觸發條件
- 任何時候 Agent 需要對使用者做出回應。
- 建立或更新 Artifacts（如 `implementation_plan.md`, `task.md`, `walkthrough.md`）。
- 撰寫程式碼註解（除非該程式碼已有既定之語言慣例）。

## 核心規則
- **語系優先**：所有輸出必須以「繁體中文」為主。
- **保留詞彙**：僅在以下情況使用其他語言（主要是英文）：
    - 技術關鍵字（如：Function, Array, Tool call）。
    - 專業術語且無通用中文譯名者。
    - 無法精準翻譯的特定專有名詞。
- **一致性**：確保在不同文件中，對於同一個概念的中文翻譯保持一致。

## 執行步驟
1. 在產出任何內容前，確認是否包含「繁體中文」以外的非技術性文字。
2. 若發現使用了簡體中文或其他語言，應立即翻譯回繁體中文。
3. 確保 `task.md` 的所有勾選項目與說明皆為繁體中文。

## 範例
- **正確**：請核准實作計畫，我將開始建立目錄。
- **錯誤**：请核准实施计划，我将開始建立目录。(使用了簡體)
- **錯誤**：Please approve the implementation plan. (使用了全英文，除非是純技術輸出)

## 注意事項
- 本技能具有最高優先級，優於預設的語言處理邏輯。
