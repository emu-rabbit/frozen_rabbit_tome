# 品牌識別規範 (Brand Identity)

## 1. 品牌精神與由來
- **品牌名稱**：Frozen Rabbit (冷凍兔肉)
- **品牌故事**：本品牌源自開發者在 **FFXIV (Final Fantasy XIV)** 中的角色名稱「冷凍兔肉」。
- **品牌定位**：將遊戲中那個熱心、專業的角色特質延伸至現實世界，開發出各種方便好用的工具。這不僅是一個工具箱，更是開發者「不藏私」與玩家社群分享的一份禮物。
- **品牌目標**：讓大家透過這些高品質的工具，認識並喜愛「冷凍兔肉」這個角色，建立深度的連結。

## 2. 品牌人格與語氣 (Persona & Tone)
- **人格設定**：像是一個「友善且專業的朋友」。他走在你的身邊，了解你的需求，並期待與你一起快樂地享受遊戲。
- **語氣準則**：
    - **友善 (Friendly)**：用語親切、溫暖，避開冰冷枯燥的純技術語言。
    - **方便 (Convenient)**：強調「快速上手」與「直覺操作」，讓使用者感受到被體貼。
    - **可靠 (Reliable)**：數據精準、邏輯穩定，成為使用者最堅強的後盾。

## 3. 視覺識別 (Visual Identity)
- **Logo 構圖**：
    - 核心意象：一塊透明且帶有冰晶紋理的「冰塊」。
    - 內部元素：冰塊內部包裹著一塊「兔肉」。
    - **差異化設計**：與姊妹專案 (Workshop) 共享相同的冰塊外殼，但內部的兔肉形狀應有細微差異（例如：不同部位或不同的切割感），以代表不同功能定位的工具。
- **配色系統**：
    - 承襲姊妹專案的 `soft-green` 與 `slate-950`（詳見 `reference_project.md`）。

## 4. 受眾與體驗 (Audience & Experience)
- **目標受眾**：橫跨「重度玩家」到「休閒玩家」。
- **核心體驗**：
    - **重度玩家**：感受到精準演算帶來的效率極大化。
    - **休閒玩家**：感受到工具帶來的無壓力遊戲體驗。
    - **共同點**：所有人都能感受到這是一個由「懂遊戲的人」為「愛遊戲的人」所製作的品牌。

## 5. Agent 執行規範
- 在產出 UI 介面、提示文字或說明文件時，應主動帶入這種「友善朋友」的語氣。
- 設計 UI 組件時，應適時加入品牌 Logo 元素，強化視覺印象。
- 若需調整 Logo 圖像，應使用 `generate_image` 工具並描述「冰塊包裹兔肉」的統一風格。
