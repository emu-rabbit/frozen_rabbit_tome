# 專案使命與核心目標 (Project Mission & Core Goals)

## 1. 專案定位
本專案為 **Final Fantasy XIV (FFXIV)** 的大地使者 (Disciples of the Land) 採集職業專用的**最佳化策略演算工具**。
旨在解決玩家在面對複雜採集環境（有限的 GP、採集次數、變動的數值）時，難以憑直覺判斷出最優技能組合的問題。

## 2. 核心痛點與解決方案
- **痛點**：技能種類繁多、資源 (GP) 有限、受玩家數值 (Gathering/Perception/GP) 與節點隨機獎勵影響，計算「期望採獲量最大化」的邏輯過於複雜，人腦難以即時給出最優解。
- **解決方案**：透過網頁運算能力，執行高效的**窮舉剪枝 (Pruning)** 或**樹狀搜尋 (Tree Search)** 演算法，為使用者列出當前數值下的「最佳技能施放順序」。

## 3. 三大設計準則 (Design Pillars)

### 第一要點：資料正確性 (Data Integrity)
> 「Garbage in, garbage out.」錯誤的基礎資料與公式會導致演算結果失去價值。
- **Agent 行為準則**：
    - 演算邏輯與遊戲內機制必須嚴格掛鉤。
    - 若遇到資料疑問、遊戲公式模糊或版本更新導致的差異，**必須停下來尋求開發者 (USER) 的協助與決策**，不得自行猜測。

### 第二要點：以人為本的 UX (User-Centric UX)
> 讓多數人以最短路徑達成目標，同時兼顧專業使用者的深度需求。
- **Agent 行為準則**：
    - **效率優先**：確保核心流程（輸入數值 -> 得到策略）流暢且無干擾。
    - **非侵入式深度功能**：特殊需求應有路徑可達成，但不應阻礙普通使用者的主線流程。
    - **決策衝突**：若設計上出現「易用性」與「專業性」的取捨問題，應主動徵詢開發者意見。

### 第三要點：輔助功能與舒適度 (Accessibility & Comfort)
> 提供高品質的多語系支援與視覺體驗。
- **Agent 行為準則**：
    - **多國語系 (I18n)**：必須維持繁體中文 (tw)、簡體中文 (cn)、日文 (ja)、英文 (en) 的支援。
    - **視覺模式**：確保在明亮模式 (Light Mode) 與黑暗模式 (Dark Mode) 下皆有優質表現。
    - **功能回歸測試**：任何新功能或 Bug 修正，皆須確保上述輔助功能正常運作，不產生破壞。

## 4. 決策邊界
當任務涉及以下情況時，應主動觸發諮詢：
1. 發現遊戲機制的新數據或不確定的公式邊界。
2. 進行 UI 改動時，可能影響到快速操作路徑。
3. 新功能可能破壞 I18n 或視覺模式的一致性。
